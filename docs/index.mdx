# Bombay Entity

Bombay Entity maps stable, typed entity identifiers to temporary actor
incarnations. It owns activation, admission, routing, draining, passivation,
generation safety, and lifecycle telemetry for a local in-memory runtime.

See the [API reference](https://docs.rs/bombay-entity).

Read the [architecture](./architecture) for the lifecycle, ownership, and
correctness model.
